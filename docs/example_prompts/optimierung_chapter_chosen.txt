Definition 3.1.1:
Es sei Ω⊂Rn eine konvexe Menge. Eine Funktion f : Ω→R ist
konvex, falls
f(λx + (1 −λ)y) ≤λf(x) + (1 −λ)f(y)
für alle x, y ∈Ωund alle λ ∈[0, 1].

Satz 3.1.5:
Es sei Ω⊂Rn eine konvexe Menge. Eine Funktion f : Ω→R ist genau
dann konvex wenn epi f eine konvexe Menge ist.

Definition 3.1.6:
Es sei C ∈Rn eine konvexe Menge und z ∈∂C. Eine Hyperebene
{x ∈Rn : ⟨x, v⟩= a}
mit v ∈Rn und a ∈R heißt Stützhyperebene an C in x, falls ⟨z, v⟩= a und ⟨x, v⟩≤a
für alle x ∈C gilt.
Der folgende Satz zeigt, dass es zu jeder konvexe Menge in jedem Randpunkt eine
Stützhyperebene gibt.

Satz 3.1.7:
Es sei C ⊂Rn eine konvexe Menge und z ∈∂C. Dann gibt es ein
v ∈Rn und ein a ∈R mit ⟨z, v⟩= c und ⟨x, v⟩≤c für alle x ∈C.

Definition 3.1.8:
Es sei Ω⊂Rn eine konvexe Menge, f : Ω→R eine konvexe
Funktion und ξ ∈Ω. Ein Vektor g ∈Rn heißt Subgradient von f bei ξ, falls
f(x) ≥f(ξ) + ⟨g, x −ξ⟩
für alle x ∈Ωgilt. Die Menge
∂f(ξ) = {g ∈Rn : g Subgradient von f bei ξ}
nennt man Subdifferential von f bei ξ.

Satz 3.1.9:
Es sei Ω⊂Rn eine konvexe Menge und f : Ω→R eine konvexe
Funktion. Dann besitzt f in jedem Punkt ξ ∈Ω◦, d.h. in jedem Punkt im Inneren

Satz 3.1.10:
